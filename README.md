# Симулятор Заводчанина — «Завод №17»

Однофайловая Telegram Mini App игра: HTML + CSS + чистый JavaScript (без сборки и зависимостей).

## Локальный запуск
Откройте `index.html` в браузере. Для Telegram Mini App нужен HTTPS-хостинг.

## Публикация на GitHub Pages
1. Загрузите содержимое архива (`index.html`, `README.md`, `.nojekyll`) в корень репозитория.
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Дождитесь публикации и скопируйте HTTPS-адрес.

## Подключение к Telegram
1. Создайте бота через @BotFather.
2. `/newapp` (или Bot Settings → Menu Button) и укажите адрес GitHub Pages.
3. Запускайте игру кнопкой Mini App.

## Что нового в версии 3
- **10 ступеней карьеры:** 5 разрядов дробеструйщика, затем бригадир → мастер → начальник цеха → главный инженер → директор.
- **Повышение только через экзамен.** Нужны опыт, уважение начальства и коллег, накопленные знания. Знания копятся учёбой (долго, дорого, отнимает много энергии и настроения), со временем забываются и обнуляются после повышения. Шанс сдачи зависит от знаний, самочувствия, трезвости; провал — потеря взноса и части знаний, пересдача через 3 смены.
- **Шкалы:** здоровье, энергия, настроение, уважение начальства, уважение коллег, крутизна, плюс стукачество, выговоры, риск увольнения, качество работы, степень опьянения.
- **Взаимосвязи:** плохие отношения с коллективом бьют по настроению и здоровью, а те — по качеству работы, зарплате и браку. Здоровье в ноль — конец игры.
- **Выговоры:** 3 выговора = увольнение. Уважение начальства, стукачество и профсоюз повышают шанс, что нарушение «пронесёт». Выговоры снимаются извинением или 5 чистыми сменами.
- **Приколюхи:** пивко, водка с коллегой, танцы на столе, песня, трюк с сигаретой, спаивание стажёра, анекдоты, карты на деньги, драка, подстава, стук мастеру, подлизывание, бутылка начальнику, вынос металлолома.
- **Происшествия:** укус крысы, падение со стеллажа, простуда, пожар от трюка и другие (около 25 событий с выбором).
- **Профсоюз:** предложение появляется по ходу игры; 7% зарплаты в обмен на защиту и путёвки.
- **Отпуск:** после 7 смен можно уйти в отпуск; с путёвкой — полное восстановление.
- **Статусы игрока:** «Стукачёк херов», «Раздолбай алкаш», «Работяга», «Золотая середина», «Душа компании», «Любимчик начальства», «Изгой», «Трудоголик» и др.
- **Концовки:** увольнение, списание по здоровью, уход по собственному, победа — директор завода.
- **Сложность:** в автотестах простые боты не доходили до директора ни в одной из сотен партий.

## Сохранение
Прогресс хранится в localStorage (ключ `zavodchanin_game_v3`) внутри Telegram WebView. Между устройствами не синхронизируется. Сохранения старых версий не подхватываются.

## Внешние ресурсы
Telegram WebApp SDK и Google Fonts (Russo One, Roboto Condensed). Без шрифтов игра работает на системных.
